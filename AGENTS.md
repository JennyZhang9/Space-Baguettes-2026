# Website editing instructions

After every website edit, check that the published website link in the root README.md (outside astra-pulse/) matches the current site entry point and release refresh tag. Update only that link and its label when necessary, preserving the rest of the README unless the task separately requires documentation changes.

Use https://jennyzhang9.github.io/SpaceBaguette.github.io/astra-pulse/index.html as the published entry point. When updating asset versions for a release, align the README URL's refresh query with that release identifier. A refresh query bypasses an older cached HTML response; it does not deploy local files. Do not claim that local changes are live without verifying deployment.

This is a standing user preference for all future website changes in this repository.
